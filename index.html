SattarEdith Pro

نسخه ۲.۰ — ویرایشگر حرفه‌ای تصویر تحت وب

درباره پروژه

سلام، من عبدالستار رحیمی هستم و این یه پروژه دانشجویی هستش که با کمک این ابزار میتونید خیلی راحت تصاویر خودتون رو ویرایش کنید.

تکنولوژی‌ها

  • HTML5 Canvas API برای پردازش pixel-level تصویر
  • JavaScript خالص (Vanilla JS) بدون فریم‌ورک سنگین
  • Supabase برای ثبت‌نام/ورود و ذخیره اطلاعات کاربران
  • Google Fonts برای فونت‌های فارسی و لاتین
  • Glassmorphism Design با CSS3 پیشرفته
  • کاملاً سازگار با GitHub Pages (Static)
